# Harness Review Notes

## Review Surfaces

The project compares three artifact classes:

1. GNUstep `ThemeDemo`
2. WinUI 3 reference app
3. Real-app validation captures, starting later with `ObjcMarkdown`

## Rules

- page IDs must remain stable once captures exist
- section IDs must remain stable once captures exist
- fixture IDs must remain stable within a section
- harnesses are comparison tools, not final truth
- real Windows behavior outranks a harness if the two disagree

## Review Standard

The review question is:

Does the GNUstep result belong to the same Windows desktop design language as
the WinUI 3 reference app, with differences only where GNUstep conventions
intentionally require them?
